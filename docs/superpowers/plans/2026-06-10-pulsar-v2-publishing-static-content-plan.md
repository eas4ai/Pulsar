# Pulsar V2 Publishing and Static Content Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expand the existing article system into community publishing with revisions, review states, scheduled publishing, autosave, stronger markdown rendering, and RSS/static content support.

**Architecture:** Extend `Article` rather than creating a second post model. Store revision snapshots in `ArticleRevision`, render markdown through the shared content service, and keep first-party docs generated by `docs:build`.

**Tech Stack:** Existing article model/controller patterns, chrono scheduling, Suprnova form validation, Vue `useForm`, Vuetify editor components, loopback HTTP tests.

## Tasks

### Task 1: Article Workflow State Expansion

- [ ] Write failing tests for:

- [ ] Add columns to `articles`: `submitted_at`, `approved_at`, `approved_by`, `scheduled_at`, `archived_at`, `reviewer_note`, `featured`, `official`.
